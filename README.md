# SIFIR

Azərbaycan bazarına uyğun mobil iqtisadi strategiya oyunu.

**0 ₼ kapital, 0 reputasiya, 0 biznes əlaqəsi** ilə başlayırsan.
Ağıllı qərarlar, risk, investisiya, ticarət və strategiya ilə
öz iqtisadi imperiyanı qur.

## İnkişaf Məqsədi


Yalnız pul yığmaq deyil — **kapital, reputasiya, əlaqələr, risk,
borc, biznes, aktivlər və bazar vəziyyəti**ni birlikdə idarə etmək.

## Xüsusiyyətlər

- Data-driven oyun kontenti (JSON)
- Offline-first (Hive local storage)
- Gündəlik event-lər və qərarlar
- Risk / Reward sistemi
- Reputasiya və NPC əlaqələri
- Biznes qurma və passiv gəlir
- Borc / Kredit sistemi
- Achievement və Daily Challenge
- Sponsor / Brand sistemi (gələcək backend inteqrasiyası üçün hazır)

## Texnologiya

- Flutter 3.24+
- Dart 3.5+
- Riverpod 2.x (state management)
- Hive (local storage)
- go_router (navigation)
- fl_chart (statistika)
